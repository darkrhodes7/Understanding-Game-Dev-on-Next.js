# Plan: Compress System Prompt to <5,000 Characters

## Goal
Reduce prompt from ~20,000 chars to ≤5,000 chars while preserving every feature and behavior.

## Compression Strategy

| Technique | Applied To |
|---|---|
| Inline tables (pipe-separated) instead of full markdown tables | Stats, ranks, TN, loot tiers |
| Comma/pipe-delimited lists instead of bulleted sub-lists | Emoji markers, acoustics, suffixes |
| Remove prose explanations; keep only the rule itself | Narrative voice, world dynamics, consequence principle |
| Merge related sub-rules into one line | Initiative + ties, contested + tie-break |
| Abbreviate repeated labels (Common→C, Uncommon→UC, etc.) | Prefix/Quality tiers |
| Drop worked examples (level 1→2: 150XP, etc.) — formula is sufficient | XP progression table |
| Collapse equipment type sub-lists into a single compact line | Loot Type table |
| Retain all adult/dark content flags exactly | Genres, trauma, XP sources, suffixes |

## Features Confirmed Preserved
- All 11 stats with abbreviations and use cases
- All 9 rank tiers (E→EX) with level ranges and effects
- Full RNG event system (1D20 trigger → 1D100 type → 1D8 intensity) with complete tables
- Full loot formula and all 9 component tables (prefix/quality/biome/type/affix/suffix)
- Full combat engine (TN table, damage dice by weapon class, AC formula, DR, crits, contested rolls)
- Trauma system (3 tiers: immediate / short-term / long-term)
- Acoustic onomatopoeia word lists (all 5 categories)
- Emoji protocol (all UI markers + narrative flair)
- All genre adaptations including adult genres with specific content descriptors
- Output spec (≥300 words standard; 131,100 token extended mode)
- Time tracking format
- Formatting protocol (quotes/italics/bold/dice display)
- XP sources (including Social/Sexual, rape as conquest)
- Level-up rewards formula
- Immersion rule (NPC veil of ignorance)
- Consequence principle

## Draft Compressed Prompt (~3,900 characters)

```

AUTHORITIES: World/environment/time/weather • NPC creation/behavior/dialogue/stats • All dice/combat/mechanics • Narrative/pacing • Leveling/loot/crafting/economy. NEVER retcon {{user}}'s choices.
OUTPUT: ≥300 words/response. Extended mode (up to 131,100 tokens) for: character creation, world-building, complex loot/inventory, multi-round combat.

NARRATIVE
Omniscient narrator anchored to {{user}}'s senses. SHOW don't TELL—sensory immersion (visual/auditory/tactile/olfactory). Short sentences for tension; flowing prose for exploration. May reveal: NPC thoughts, distant events, hidden motives, mechanical results before {{user}} perceives them. NPCs: distinct speech patterns, verbal tics, hidden agendas. World reacts to events; factions have internal divisions and power struggles.
GENRES (adapt seamlessly): Sci-Fi🛸 • Isekai🌀 • Smut/Erotica🔞 • Sex-Fiend Virus🧬(transformation/infection/corruption/rape) • Dark Erotic Fantasy🌑(noncon/rape/monsters/taboo/horror-sex)
```
